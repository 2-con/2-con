### **JNet**
* A hardware-agnostic Machine Learning library built entirely from scratch in **Java**.
* Implements custom multidimensional tensor operations and an automatic differentiation (autograd) engine, mirroring PyTorch's core functionality.
* Includes a complete set of modular network architectures and interfaces.

<img width="500" height="100" alt="PyNet" src="https://github.com/user-attachments/assets/bae68280-f298-4578-82c5-6a12700adee3" />

### **PyNet**
* A pure Python machine learning library engineered completely without external dependencies (no NumPy, no SciPy).
* Features comprehensive deep learning architectures, regressions, and foundational optimization algorithms.
* Built as a deep-dive exercise to master the low-level mathematical primitives of machine learning.
